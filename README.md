# TDD_CS

Calculadora desenvolvida com HTML, CSS e JavaScript, com testes automatizados em Python usando Selenium para aplicar conceitos de TDD (Desenvolvimento Orientado a Testes).

* **TDD:** O código gera e valida **909 cenários de testes**, incluindo:
  * Operações de soma, subtração, multiplicação e divisão (1 a 15).
  * Contas com números decimais.
  * Tratamento de erros (ex: letras na conta `2+a`, múltiplos operadores `2+2+2`, ausência de operadores).
